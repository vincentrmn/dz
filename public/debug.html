Aide au diagnostic

Un run reste « en cours » ? Ouvrir n8n → Executions du workflow « DZ — Générer rapport chantier » pour voir le nœud en échec.

Erreur Traxxeo ? L’accès API est payant : vérifier que l’offre est signée et que le credential « Traxxeo API » est renseigné, puis passer traxxeo_actif à true dans le nœud « Config » du workflow.

Erreur Teams / Graph ? Vérifier le credential « Microsoft Graph DZ » et les IDs de conversations BLL / RT du chantier.

Pas de PDF ? Vérifier le credential « PDFShift » et le drapeau pdfshift_actif dans le nœud « Config ». Le Word et l’aperçu HTML sont générés même sans PDFShift.
